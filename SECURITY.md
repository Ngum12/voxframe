# Security

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Report it
privately through GitHub:
[**Report a vulnerability**](https://github.com/Ngum12/voxframe/security/advisories/new)
(the *Security* tab of the repository, then *Report a vulnerability*). Only the
maintainers can see it.

If you cannot use GitHub, write to CONTACT_EMAIL_TBD.

Please include what you found, how to reproduce it, and which version you used.

## Supported versions

Only the latest release receives security fixes.
